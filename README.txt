STOCK PROFIT TRACKER PRO

1. Install Python 3.10+.
2. Double-click START_TOOL.bat.
3. The browser will open the app.
4. Add Papa/Mummy stock transactions.
5. Profit/share and total profit are calculated automatically.
6. Use Export to create Excel, PDF and CSV backup.

The first launch is preloaded with the five transactions already supplied:
HFCL (13 May 2026), three Indo MIM entries, and Glasswall Systems.

The database is local: stock_tracker.db.
